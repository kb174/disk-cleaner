# DiskCleaner — анализатор диска для Windows

Программа с окном для поиска того, что занимает место на диске: больших файлов, тяжёлых папок, мусора и дубликатов.
Ничего не удаляет сама — только по вашей команде и только в Корзину.

> [!WARNING]
> **Вы отвечаете за то, что удаляете.** Программа предоставляется «как есть», без каких-либо гарантий.
> Списки «Мусор» и «Дубликаты» — только подсказки: программа не знает, что важно лично вам, и может ошибаться.
> Автор не несёт ответственности за потерю данных, сбои Windows или программ, вызванные удалением файлов.
> Не удаляйте системные папки (Windows, Program Files, ProgramData, AppData), если не уверены,
> и храните важные данные в резервной копии.

## Возможности

- **Интерфейс в стиле Windows 11** — светлая и тёмная тема (подхватывает тему Windows, переключается кнопкой),
  карточки дисков с заполненностью, сводка после сканирования, полоски долей у папок.
- **Большие файлы** — список от самых крупных, фильтр по имени, по «давности» (не изменялись N дней) и исключение папок.
- **Папки** — дерево, отсортированное по размеру, и плоский список с поиском по имени папки, уровнем вложенности и порогом размера.
- **Мусор** — временные файлы, логи, резервные копии, дампы памяти, кэши, папки Temp, пустые папки.
- **Дубликаты** — одинаковые файлы по содержимому (хэш BLAKE2), имена не важны.
- **Типы файлов** — сколько места занимает каждое расширение.
- **Здоровье дисков** (в духе SSD Life / CrystalDiskInfo) — ресурс SSD с прогнозом, температура, наработка,
  записано/прочитано, переназначенные и нестабильные сектора HDD, ошибки кабеля. При запуске программа проверяет
  диски и **сама предупреждает**, если с каким-то из них что-то не так.
- Контекстное меню: показать в Проводнике, открыть, скопировать путь, показать размер папки, скрыть папку, удалить в Корзину.
- Экспорт любой вкладки в CSV (открывается в Excel).
- **Защита от ошибок:** при первом запуске нужно подтвердить, что вы понимаете риски; перед каждым удалением —
  подтверждение; для системных папок и файлов программ — отдельное предупреждение (по умолчанию «Нет»);
  в группе дубликатов нельзя удалить все копии сразу.

## Скорость

Сканирование идёт в нескольких процессах (по числу ядер) с динамической балансировкой: тяжёлые папки дробятся
на части на лету, поэтому одна огромная `AppData` не тормозит остальных.

| Папка | 1 процесс | 12 процессов |
|---|---|---|
| профиль пользователя, 635 тыс. файлов, 145 ГБ | 36 с | 6.4 с |
| `C:\Program Files`, 153 тыс. файлов | 3.8 с | 0.9 с |

Число процессов подбирается автоматически по типу диска выбранной папки:

| Диск | Процессов |
|---|---|
| SSD / NVMe | по числу ядер процессора (до 16) |
| HDD, USB-флешка | 2 — параллельное чтение гоняет головку HDD и только замедляет |
| Сетевой диск | 4 |

Тип определяется через Windows (`IOCTL_STORAGE_QUERY_PROPERTY`, признак задержки позиционирования), права администратора не нужны. Значение в поле «Ядер» можно поменять вручную.

## Здоровье дисков без прав администратора

| Диски | Что читается без администратора |
|---|---|
| NVMe SSD | полный журнал здоровья NVMe: износ, резерв ячеек, температура, записано, наработка, ошибки |
| SATA HDD и SSD | SMART-атрибуты через системный запрос «прогноз отказа»; если драйвер их не отдаёт — кнопка «Перезапустить от администратора» |
| USB-диски | зависит от переходника: многие не пропускают SMART |

Исправный SMART не гарантирует, что диск не откажет внезапно, — важные данные храните в резервной копии.

## Запуск

**Готовый exe** — скачайте `DiskCleaner.exe` со страницы [Releases](../../releases) и запустите. Python не нужен.
Для полного сканирования диска `C:` запускайте от имени администратора.
Windows SmartScreen может предупредить о неподписанной программе: «Подробнее» → «Выполнить в любом случае».

**Из исходников** (Python 3.8+):

```
pip install sv-ttk
python disk_cleaner.py
```

`sv-ttk` — тема Sun Valley (вид Windows 11, светлая и тёмная). Без неё программа тоже работает, но в стандартном оформлении.

## Сборка exe

```
pip install pyinstaller sv-ttk
pyinstaller --onefile --windowed --name DiskCleaner --collect-data sv_ttk disk_cleaner.py
```

Готовый файл появится в папке `dist`.

## Проверка без окна

```
DiskCleaner.exe --selftest "C:\Users" report.txt
```

Сканирует папку и записывает в `report.txt` число файлов, размер и время.
